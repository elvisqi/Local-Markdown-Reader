## Local Markdown Reader 2.3.1 官方主题重建

![Local Markdown Reader 2.3.1 theme showcase](https://fe-docs.baiteda.com/Local-Markdown-Reader/themes/previews/theme-showcase-2.3.1.svg)

本次发布包含 10 个原创远程主题包，均支持 light/dark 双模式，并通过官方主题发布校验器。

- schemaVersion: 2
- catalogVersion: 2026.07.08.official.1
- 主题包下载 URL 和预览 URL 均带版本参数，远程 catalog 支持刷新缓存失效。
- 每套主题包含设计合同、相似度报告、Chrome headless 真实截图报告和发布校验报告。

官方主题：

- Minimal Manuscript
- Things Native
- Topaz Lab
- Primary Soft
- Prism Spectrum
- Sanctum Archive
- Terminal Console
- Nord Research
- Everforest Field
- GitHub Workbench
